## 一、项目开源介绍

怪兽国度 (Monster Kingdom) 是一款基于 GameCreator 引擎开发的 2D 俯视视角 ARPG 即时战斗角色扮演游戏。

本项目是对 **4399 经典页游《怪物世界》** 的公益怀旧开源复刻，旨在让老玩家能够重温当年的游戏回忆。

### 核心特性

- **即时战斗系统** - 流畅的 ARPG 战斗体验
- **多控制器支持** - 键盘、鼠标、游戏手柄
- **丰富插件系统** - 任务、成就、锻造、好感度等
- **云端存档** - 服务器端存档同步
- **排行榜系统** - 全服玩家排行

### 开源内容

本项目已全部开源，包括：

| 模块 | 说明 | 状态 |
|------|------|------|
| 游戏客户端 | TypeScript 源代码 | ✅ 开源 |
| 服务器端 | PHP API 代码 | ✅ 开源 |
| 游戏资源 | 素材、配置文件 | ✅ 开源 |
| 开发文档 | 技术文档 | ✅ 开源 |

### 技术架构

| 分类 | 技术 | 说明 |
|------|------|------|
| 游戏引擎 | GameCreator | 核心游戏引擎 |
| 客户端 | TypeScript | 游戏逻辑开发 |
| 服务端 | PHP | API 服务器 |
| 数据库 | JSON/File | 数据存储 |

## 三、模块详解

### 3.1 核心模块

#### 游戏入口 (GCMain)

```typescript
let Game: ProjectGame = new ProjectGame();
GameGate.start();
```

#### 场景控制器 (GameGate)

管理游戏场景切换、存档读取。

| 状态 | 说明 |
|------|------|
| `STATE_0` | 离开场景 |
| `STATE_1` | 加载场景 |
| `STATE_2` | 执行进入事件 |
| `STATE_3` | 场景完成 |
| `STATE_4` | 玩家可控制 |

#### 战斗系统 (GameBattle)

核心战斗流程控制，每 6 帧刷新一次。

### 3.2 UI 界面系统

| 界面 | 文件 | 功能 |
|------|------|------|
| 主界面 | `GUI_Main.ts` | 状态栏、快捷操作 |
| 技能 | `GUI_Skill.ts` | 技能列表、详情 |
| 背包 | `GUI_Bag.ts` | 物品管理 |
| 角色 | `GUI_Actor.ts` | 属性查看 |
| 任务 | `Lmkrt_GUI_Mission.ts` | 任务追踪 |
| 成就 | `Lmkrt_GUI_Achievement.ts` | 成就解锁 |
| 好感度 | `Lmkrt_GUI_Favor.ts` | NPC 好感度 |
| 锻造 | `Crafting_system.ts.ts` | 装备强化 |

### 3.3 网络系统

#### 服务端 API (fwq/)

| 文件 | 功能 |
|------|------|
| `api.php` | 账号、存档、排行榜 |
| `secure_save_api.php` | 加密存档 |
| `index.html` | 登录页面 |
| `ranking.html` | 排行榜 |
| `chat.html` | 聊天室 |
| `save_load.html` | 云存档 |

## 四、快速开始

### 环境要求

- Node.js >= 16
- PHP >= 7.4
- Web 服务器 (Nginx/Apache)

### 安装

```bash
# 克隆项目
git clone https://github.com/worddream666/gsgd666.git
cd gsgd666

# 安装依赖
npm install
```

### 开发

```bash
# 开发模式（监视编译）
npm run watch

# 构建项目
npm run build
```

### 部署

#### 前端部署
1. 构建: `npm run build`
2. 将 `Game/dist/` 部署到 Web 服务器

#### 后端部署
1. 将 `fwq/` 部署到 PHP 服务器
2. 配置数据库连接
3. 设置密钥（生产环境必须）

## 六、那些年，我们的回忆

还记得小学的那个夏天，第一次点开 4399 里的图标，冲进怪物世界的彩虹森林，跟着聪聪猪一起打第一个淘气猪。那时候攒了好久的材料，一点点锻造，终于做出了心心念念的狐狸套装，看着面板上的战力，以为这个世界会一直在这里，等我们慢慢探索，等我们打完所有的怪物，等我们和小伙伴一起刷完所有的副本。

后来我们才明白，2015 年开始，开发团队就已经面临资金困境，没有新的更新，老玩家慢慢流失。为了生存，工作室不得不转型去做手游，怪物世界就这样慢慢停服了。2018 年的秋天，服务器再也连不上了，背包里的材料、攒了好久的套装、和朋友约好的下次上线，全都一下子没了踪影。

这么多年过去，我们从小学的孩子，变成了上班的大人，有了新的生活，新的朋友，可心里总还有一块地方，留着那个彩虹森林，留着那只淘气猪，留着当年攒了好久的狐狸套装。

现在，这个世界回来了。我把它重新搭建起来，取名叫 **怪兽国度**。这不是什么商业游戏，只是一个给老玩家的公益服，没有充值，没有盈利，只是想让我们这些想念它的人，能重新回到那个世界，穿上当年的套装，再打一次野猪，再逛一次热带雨林，把当年没做完的梦，做完。

这份回忆，我不想再让它消失了。所以我把它开源了，这样就算以后我没办法维护了，还有别人可以接着做，这个世界，就会一直在这里，**永远不会再关服了**。
